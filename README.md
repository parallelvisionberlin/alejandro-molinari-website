# Alejandro Molinari

Independent artist portfolio with a minimal editorial layout and selected music, film, and print collaborations.

## Status

Draft ready for review on Cloudflare Pages. Do not change alejandromolinari.com DNS or cancel WordPress until the new preview is approved.

## Deployment

Cloudflare Pages, connect this GitHub repository. Set the production branch to `main`, choose framework `None`, leave build command empty, and publish from output directory `.`.

## Contents

`index.html`, `styles.css`, `script.js`, `assets/`, `favicon.svg`, `_headers`, `robots.txt`, `sitemap.xml`.

Photographs are temporary lower-resolution previews extracted from the artist's WordPress site screenshots. Replace with approved originals before final domain migration. Vogue, Purple, and music references are supplied as links. No WordPress export, contact-form messages, customer email addresses, or passwords are included in this repository.
